# F5Voice — локальная диктовка вместо системной

Нажал клавишу — говоришь — нажал ещё раз — текст напечатан в активном поле.
Распознаёт whisper (large-v3-turbo) целиком на своей машине, в интернет ничего
не уходит. Русский по умолчанию, английские названия латиницей, голосовые
команды для символов и переносов.

- **macOS на Apple Silicon** — основная версия: приложение в строке меню,
  плашка Liquid Glass, mlx-whisper на GPU.
- **Windows и Linux** — версия на Python и faster-whisper: значок в области
  уведомлений, та же логика распознавания. Подробности в [other/README.md](other/README.md).

## Установка одной командой

Ничего заранее ставить не нужно: команда сама скачает недостающее и всё настроит.

**macOS** — открой Терминал (Cmd+Space, набрать Terminal), вставь и нажми Enter:

```
curl -fsSL https://raw.githubusercontent.com/axepq/f5voice/main/get.sh | bash
```

Если появится окно про Command Line Tools — нажми «Установить» и подожди,
команда продолжит сама. В конце macOS спросит два разрешения: Микрофон и
Универсальный доступ.

**Windows** — открой PowerShell (Пуск, набрать PowerShell), вставь и нажми Enter:

```
irm https://raw.githubusercontent.com/axepq/f5voice/main/get.ps1 | iex
```

**Linux** — в терминале:

```
curl -fsSL https://raw.githubusercontent.com/axepq/f5voice/main/get.sh | bash
```

Установка занимает несколько минут: скачивается модель распознавания
(около 1,5 ГБ) и Python-пакеты. На Windows при отсутствии Python и Git они
ставятся через winget, на Linux пакеты ставятся через apt, dnf или pacman
(спросит пароль). Автозапуск включается сам. На Linux и Windows клавиша по
умолчанию Ctrl+Alt+Space, на маке F5. Повторный запуск той же команды
обновляет установку. Удаление: `~/.f5voice/src/uninstall.sh` на маке,
`other/uninstall-linux.sh` и `other/uninstall.ps1` на остальных. На Linux
под Wayland глобальные клавиши недоступны: установщик подскажет назначить
сочетание рабочего стола на команду `dictate.py --toggle`.

### macOS подробнее

Нужны Command Line Tools (установщик сам предложит их поставить) и около
2 ГБ места: модель 1,5 ГБ и Python-пакеты. Установщик создаёт `~/.f5voice` с Python-окружением, скачивает модель,
собирает приложение системным `swiftc`, включает автозапуск. При первом
запуске macOS спросит два разрешения: **Микрофон** (кнопка «Разрешить») и
**Универсальный доступ** (Системные настройки → Конфиденциальность и
безопасность → включить F5Voice). Пока второго нет, иконка микрофона в
строке меню перечёркнута.

Обновление: `git -C ~/.f5voice/src pull && ~/.f5voice/src/install.sh`.
Разрешения после пересборки сохраняются. Удаление: `~/.f5voice/src/uninstall.sh`.

## Как пользоваться

```
F5      начать запись — звук, красный микрофон в меню, плашка с уровнем внизу
F5      закончить — через 1–3 секунды текст печатается туда, где курсор
Esc     отменить запись или распознавание
```

Первую фразу после долгого простоя модель грузит параллельно с записью,
ждать не нужно. Потолок одной записи — 3 минуты, длинные записи
распознаются целиком.

### Голосовые команды

«новая строка», «абзац», «плюс», «минус», «равно», «слэш», «обратный слэш»,
«звёздочка», «решётка», «собака», «амперсанд», «знак процента», «знак
доллара», «подчёркивание», «тире», «дефис», «стрелка», «открыть/закрыть
скобку», «открыть/закрыть кавычки», «точка», «запятая», «двоеточие», «точка с
запятой», «вопросительный знак», «восклицательный знак», «многоточие».

| сказано | напечатано |
|---|---|
| src слэш components точка tsx | `src/components.tsx` |
| alex собака gmail точка com | `alex@gmail.com` |
| пять минус три равно два | `5 - 3 = 2` |
| текст абзац дальше | `текст` ↵ ↵ `Дальше` |

Слова «точка» и «минус» в обычной речи тоже станут символами; лишнее можно
убрать из списка `COMMANDS` в `common/textproc.py`. Перенос строки
печатается как Shift+Enter, в терминалах — Option+Enter, чтобы в чатах и в
Claude Code не отправлять сообщение.

## Настройки — `~/.f5voice/config.json`

После правки: меню F5Voice → «Перечитать настройки». Ошибка в JSON или
непонятная клавиша не ломают работу: приложение сообщает об этом плашкой и
остаётся на прежних настройках. Проверить файл без перезапуска:

```
~/.f5voice/F5Voice.app/Contents/MacOS/F5Voice --check
```

| ключ | по умолчанию | что |
|---|---|---|
| `hotkey` | `F5` | любая `F1`–`F20` или сочетание с модификатором: `cmd+shift+space`, `ctrl+alt+d`, `option+F13`. Одиночная буква или пробел без модификатора не принимается |
| `languages` | `ru,en` | первый — основной; второй берётся, только если модель уверена на `alt_language_min_prob` |
| `alt_language_min_prob` | `0.95` | ниже — whisper начинает переводить русскую речь на английский |
| `model` | `mlx-community/whisper-large-v3-turbo` | любая модель из mlx-community; `whisper-medium` и `whisper-small` легче |
| `prompt` | стандартная | подсказка модели: стиль и часто произносимые названия латиницей |
| `trailing_space` | `true` | пробел после надиктованного |
| `max_record_seconds` | `180` | потолок записи |
| `idle_unload_minutes` | `15` | простой, после которого модель выгружается из памяти (1,5 ГБ) |
| `newline_in_terminals` | `option` | чем печатать перенос в терминалах: `option`, `shift`, `none` |
| `newline_elsewhere` | `shift` | то же для остальных приложений |

F1–F12 на клавиатурах Apple в медиарежиме шлют не клавишу, а медиакод
(F5 — «Voice Command»), поэтому выбранная F-клавиша переводится через
`hidutil` в незанятую F17 и её системная функция на время работы отключается.
При выходе из приложения перевод снимается. Сочетания с модификаторами и
F13–F20 ловятся напрямую.

## Как это устроено

```
клавиша → hidutil (F-клавиша → F17) → F5Voice.app (Swift, CGEventTap)
        → запись AVFoundation 16 кГц → macos/worker.py (mlx-whisper, модель в памяти)
        → common/: детектор речи, выбор языка, сборка сегментов, команды, чистка
        → печать CGEvent-ами в активное поле
```

Ключевые решения, к которым пришли на практике:

- Тишина отсекается до модели: whisper на пустой записи галлюцинирует и думает
  десятки секунд. Щелчки клавиш речью не считаются.
- Язык выбирается только из списка `languages`, с приоритетом первого: иначе
  русский путался с украинским, а при перевесе английского whisper переводил.
- Контекст переносится между 30-секундными окнами: без него окно с английскими
  словами терялось целиком, а названия писались транслитом.
- Сегмент латиницей при русском токене перепроверяется по звуку и декодируется
  заново с русским контекстом — это лечит дрейф в английский.
- Подпись приложения ad-hoc, но с явным требованием по идентификатору бандла,
  поэтому TCC не просит разрешения заново после каждой пересборки.

## Файлы

| | |
|---|---|
| `get.sh`, `get.ps1` | загрузчики для команды установки: ставят git, клонируют, запускают установщик |
| `install.sh`, `uninstall.sh` | установка и удаление на macOS |
| `macos/main.swift` | приложение: перехват клавиши, запись, плашка, меню, печать |
| `macos/worker.py` | воркер mlx-whisper |
| `common/` | общее ядро: `audio_io`, `vad`, `textproc` (команды), `segments`, `selftest` |
| `other/dictate.py` | версия для Windows/Linux на faster-whisper |
| `other/install-linux.sh`, `other/install.ps1` | установщики для Linux и Windows, рядом деинсталляторы |
| `~/.f5voice/` | установленное: `F5Voice.app`, `venv`, `config.json`, `f5voice.log`, `last.wav` |

Самопроверка ядра без модели: `python -m common.selftest`.
Если распознало криво — последняя запись лежит в `~/.f5voice/last.wav`,
язык и уверенность каждой фразы — в `~/.f5voice/f5voice.log`.
