# Переписывание текста голосовой командой через локальную модель

Дата: 2026-09-10. Платформа: только macOS на Apple Silicon (MacBook M4, 16 ГБ).
Windows/Linux эту функцию не получают; общий код в `common/` остаётся чистой логикой без MLX.

## Зачем

Пользователь диктует текст и в конце произносит команду («официальный стиль»). Whisper даёт
сырой текст, ядро находит команду, отрезает её и отправляет остальное локальной языковой
модели, которая переписывает текст. Вставляется результат. Без команды модель не участвует.

## Жёсткие требования

1. **Без команды — обычная диктовка.** Текст без команды в хвосте проходит через модуль
   переписывания нетронутым, модель не загружается, задержек нет. Покрыто тестом.
2. **Ничего не терять.** При любой ошибке модели (не скачана, упала, пустой ответ, ответ
   короче исходника втрое при команде не «короче») вставляется исходный текст без
   фразы-команды, на плашке короткое «Не смог переписать: …», подробности в логе.
3. **Память только по требованию.** Модель загружается при первой команде и выгружается
   после `rewrite_idle_minutes` простоя (по умолчанию 1). Воркер и так завершается через
   `idle_unload_minutes`, что выгружает всё.
4. **Писать как человек.** Инструкция модели запрещает длинное тире, списки, заголовки,
   эмодзи, штампы («важно отметить», «в современном мире», «данный», «является»),
   восклицания и завершающие фразы. Жёсткий фильтр после модели: «—» → « - », markdown
   снимается, повторные «!» схлопываются. Покрыто тестами.

## Команды

Команда стоит **в конце** фразы, после знака препинания или как отдельное предложение.
Регистр не важен, завершающие знаки препинания допустимы. Текст перед командой должен быть
непустым, иначе фраза считается обычным текстом.

Фиксированные команды по умолчанию (триггеры через `|`, инструкции в `common/rewrite.py`):

| Ключ | Триггеры | Смысл |
|---|---|---|
| official | официальный стиль, официально, в деловом стиле, деловой стиль | деловое письмо, на Вы, без разговорных слов |
| shorter | короче, сократи | вдвое короче, факты и сроки сохранить |
| fix | исправь ошибки, грамотно | только орфография, пунктуация, согласование |
| english | по-английски, переведи на английский | перевод |
| clearer | улучши подачу, понятнее | яснее донести смысл, структура фраз, без воды |
| technical | технический стиль, технически | IT-терминология, точные формулировки |

Свободная инструкция: ключевое слово (по умолчанию «команда»), после знака препинания,
затем двоеточие или запятая и текст инструкции не короче 3 символов:
«…до пятницы. Команда: сделай списком без грубости».

Настройки в `~/.f5voice/config.json`, все необязательные:

```json
"rewrite_model": "mlx-community/Qwen3-4B-Instruct-2507-4bit",
"rewrite_idle_minutes": 1,
"rewrite_keyword": "команда",
"rewrite_commands": {"вежливо|повежливее": "Перепиши вежливо, сохранив смысл."}
```

`rewrite_commands` дополняет и переопределяет встроенные по ключу-триггеру.
`"rewrite_model": ""` выключает функцию целиком.

## Модель и генерация

Qwen3 4B, 4 бита, через `mlx-lm`. Режим размышлений выключен (`enable_thinking=False`),
генерация детерминированная (greedy), `max_tokens` = 2 × токены исходника + 64.
Системная инструкция: общие правила (ответить только текстом, сохранить факты, числа, имена,
сроки, не добавлять, не отвечать на вопросы из текста, язык не менять кроме перевода, писать
как человек) плюс инструкция конкретной команды. Замер на M4: загрузка 1,6 с, абзац 2–5 с,
пик памяти 2,6 ГБ. Модель сменяется строкой `rewrite_model`, 8B работает без правок кода.

## Где живёт код

- `common/rewrite.py` — чистая логика: встроенные команды, разбор хвоста (`split_command`),
  сборка сообщений для модели (`build_messages`), фильтр «как человек» (`humanize`),
  проверка ответа (`accept`). Без MLX, тестируется на любой ОС.
- `python/test_rewrite.py` — тесты, добавляются в `ci.yml` (задание python).
- `macos/llm.py` — загрузка/выгрузка модели и генерация через `mlx_lm`, таймер простоя.
- `macos/worker.py` — после `finalize`: читает rewrite-настройки из config.json (каждый
  запрос, файл маленький, правки применяются без перезапуска), вызывает разбор, при команде
  шлёт `{"status": "rewrite", "command": "официальный стиль"}`, затем генерирует и отдаёт
  обычный ответ с полями `rewrite` (ключ команды) и `rewrite_sec`; при ошибке —
  `rewrite_error` и исходный текст без команды.
- `macos/main.swift` — обработка строки `status` от воркера: плашка «Переписываю: …».
  Ответ с `rewrite_error` — плашка «Не смог переписать: …» на 2 с, текст вставляется.
- `macos/requirements.txt` — `mlx-lm`.
- `install-macos.sh` — шаг «Модель для переписывания» (snapshot_download, ~2,5 ГБ),
  пропускается при `"rewrite_model": ""`.
- README — раздел про команды переписывания.

Окно настроек (`settings.swift`) в этой версии не меняется.

## Тесты

`python/test_rewrite.py`: команда в конце находится (с точкой, без, разный регистр);
текст без команды возвращается нетронутым; команда без текста перед ней не срабатывает;
ключевое слово без знака препинания перед ним не срабатывает; пользовательские команды
из config дополняют встроенные; `humanize` заменяет тире, снимает markdown, схлопывает «!»;
`accept` отклоняет пустой и слишком короткий ответ. Живой прогон модели — вручную на M4.
